Zoho Books Connector Documentation

Setup

The Zoho Books connector uses REST API v3 with OAuth 2.0 authentication.

OAuth Flow
  1. Create a Zoho API client at Zoho API Console
  2. Configure the redirect URL to {% url 'zoho:oauth_callback' %}
  3. Authorize and obtain the refresh token
  4. Store client_id, client_secret, and refresh_token in the connection credentials
Data Center

Supports .com, .in, .eu data centers. Set the data_center in the connection config.

Supported Entities
  • Contacts (customers)
  • Invoices
  • Credit notes
  • Customer payments (receipts)
