Setup Instructions
{% if connector_name == 'busy' %}

1. Install BUSY 21+ with the API add-on.

2. In BUSY: Settings → API Settings → Enable API Server on port 5400.

3. Generate an API token in BUSY.

4. In PayReceivio: Add connection with api_url, company_code, and api_token.

{% elif connector_name == 'marg' %}

1. Install Marg ERP with the Marg API Server add-on (port 8999).

2. Generate an API key in Marg → Utility → API Settings.

3. In PayReceivio: Add connection with api_url, company_code, and api_key.

{% elif connector_name == 'quickbooks' %}

1. Create an Intuit Developer app at developer.intuit.com.

2. Configure redirect URI to {{ request.scheme }}://{{ request.get_host }}{% url 'accounting_connectors:docs' 'quickbooks' %}.

3. Use the OAuth 2.0 flow to obtain refresh_token.

4. Store client_id, client_secret, refresh_token, realm_id, environment in the connection.

{% elif connector_name == 'xero' %}

1. Create a Xero app at developer.xero.com.

2. Configure redirect URI and grant scopes: accounting.transactions accounting.contacts.

3. Complete OAuth 2.0 flow to obtain refresh_token.

4. Store client_id, client_secret, refresh_token, tenant_id in the connection.

{% elif connector_name == 'sage' %}

1. Register a Sage developer app at developer.sage.com.

2. Subscribe to Sage Business Cloud Accounting.

3. Complete OAuth 2.0 flow to obtain refresh_token.

4. Store client_id, client_secret, refresh_token, region in the connection.

{% elif connector_name == 'dynamics365' %}

1. Register an app in Azure AD (Entra ID).

2. Grant API permissions for Dynamics 365 Business Central.

3. Create a client secret and note the application (client) ID.

4. Complete OAuth 2.0 flow with the tenant_id.

5. Store client_id, client_secret, refresh_token, tenant_id, environment, company_id in the connection.

{% elif connector_name == 'netsuite' %}

1. In NetSuite: Setup → Integration → OAuth 2.0 Client Credentials.

2. Create an integration record with OAuth 2.0 enabled.

3. Generate client_id and client_secret.

4. Complete OAuth flow to obtain refresh_token.

5. Store client_id, client_secret, refresh_token, account_id in the connection.

{% elif connector_name == 'sap_b1' %}

1. Enable Service Layer on the SAP B1 server (HTTP 50000 / HTTPS 50001).

2. Create a user with appropriate permissions in B1.

3. In PayReceivio: Add connection with host, port, company_db, username, password.

4. The connector will manage session cookies automatically.

{% elif connector_name == 'odoo' %}

1. In Odoo: Settings → General Settings → Developer mode → Generate API key for the integration user.

2. Note the database name and the URL.

3. In PayReceivio: Add connection with host, database, username, api_key.

4. Configure journal_id and default_payment_method_line_id for receipt posting.

{% elif connector_name == 'myob' %}

1. Register a MYOB developer app at developer.myob.com.

2. Complete OAuth 2.0 flow with company file access.

3. Store client_id, client_secret, refresh_token, company_file_uid in the connection.

{% elif connector_name == 'freshbooks' %}

1. Register a FreshBooks app at freshbooks.com/api.

2. Complete OAuth 2.0 flow to obtain refresh_token.

3. Store client_id, client_secret, refresh_token, account_id in the connection.

{% elif connector_name == 'wave' %}

1. Register a Wave developer app at developer.wave.com.

2. Complete OAuth 2.0 flow to obtain refresh_token.

3. Store client_id, client_secret, refresh_token, business_id in the connection.

4. This connector uses the Wave GraphQL API.

{% elif connector_name == 'gofrugal' %}

1. Install GoFrugal HappyConnect on the GoFrugal server.

2. Generate an API key in GoFrugal → Settings → API.

3. In PayReceivio: Add connection with host, port, store_code, api_key.

{% elif connector_name == 'focus' %}

1. Enable Focus iConnect REST API on the Focus server.

2. Create a JWT-enabled user in Focus.

3. Complete the Focus OAuth flow to obtain refresh_token.

4. In PayReceivio: Add connection with host, port, company_code, refresh_token.

{% elif connector_name == 'exact' %}

1. Register an Exact Online app at apps.exactonline.com.

2. Complete OAuth 2.0 flow with the appropriate region (nl/be/de/uk/us).

3. Store client_id, client_secret, refresh_token, region, division in the connection.

{% elif connector_name == 'autocount' %}

1. Install AutoCount Task Server on the AutoCount machine.

2. Generate an API key in AutoCount → Settings → API.

3. In PayReceivio: Add connection with host, port, database_name, api_key.

{% elif connector_name == 'money_forward' %}

1. Register a Money Forward developer app at developer.moneyforward.com.

2. Complete OAuth 2.0 flow to obtain refresh_token.

3. Store client_id, client_secret, refresh_token, office_id in the connection.

{% else %}

Setup instructions for {{ connector_name }} are not yet documented.
