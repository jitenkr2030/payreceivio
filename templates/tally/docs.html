TallyPrime Connector Documentation

Setup

The TallyPrime connector uses XML over HTTP via a local agent that proxies requests from PayReceivio cloud to the on-premise Tally installation.

Agent Installation

Install the PayReceivio Tally Agent on the same Windows machine as TallyPrime. The agent connects to Tally's HTTP server (default port 9000) and exposes a secure API for PayReceivio cloud.

Supported Entities
  • Customers (Sundry Debtors ledgers)
  • Sales invoices (outstanding bills)
  • Credit notes
  • Receipt vouchers
  • Ledger balances
Receipt Write-Back

Approved receipts are posted to Tally as Receipt vouchers with bill-wise allocation. The XML format is generated by the connector and posted via the agent.
